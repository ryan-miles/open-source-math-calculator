Calculator guide

What you can do, what you can’t, and how this tool works.

What this is

An advanced expression calculator that runs 100% in your browser. Type math the way you’d write it, press Enter (or =), and get a result. History, variables, memory, unit conversion, and a simple function graph are included.

It is not a full computer-algebra system (CAS), a spreadsheet, or a symbolic equation solver. It evaluates numeric expressions (and math.js units) quickly and privately on your device.

Privacy: nothing is uploaded. Your expression, history, variables, memory, and settings stay in this browser’s localStorage only.

Limits — what you can’t (or shouldn’t) expect

  • No symbolic algebra. It will not simplify (x+1)^2 to x^2+2x+1, expand polynomials, or rearrange equations for you.
  • No equation solving. Entering 2x + 3 = 11 is not supported as a solve step. Assign values and evaluate expressions instead.
  • No calculus CAS. No symbolic derivatives/integrals as first-class features. You can plot a function numerically, but not get a closed-form antiderivative.
  • Numeric (IEEE) floating point. Results can show tiny float noise (e.g. 0.1 + 0.2). Use the fraction format when a rational approximation helps.
  • Factorial range. factorial(n) accepts integers 0…170 only (beyond that overflows normal floats).
  • Graphing is a sample, not exact. Curves are built from hundreds of points. Vertical asymptotes appear as gaps; very sharp spikes can be missed between samples.
  • Units must be recognized names. Prefer math.js-style units (m, ft, km/h, degC). Everyday aliases mph and kph are included; obscure spellings may fail.
  • Not a financial or regulatory calculator. Fine for homework and engineering scratch work; not certified for tax, medical, or legal computations.
  • Local data only. Clearing site data, another browser, or private mode wipes history/variables. There is no cloud sync or multi-device account.
  • Matrix / complex UI is minimal. math.js can handle some advanced values if you type them, but there is no dedicated matrix editor or complex-plane view.

Using the interface

  • Expression box — type freely; live preview shows a soft result while you edit. Enter commits to history.
  • History (left) — click a row’s expression to reload it; click the result line to insert that number. Clear removes the list only (not variables).
  • Variables (left) — shows user assignments and defined functions. Clear drops both maps.
  • Keypad tabs — Basic numbers/ops, Scientific functions, and More (hyperbolic, rounding, unit keywords).
  • DEG / RAD — affects trig and inverse trig. Hyperbolic functions are always “plain” (not degree-based).
  • Format & digits — change how numbers are shown; the underlying value is unchanged.
  • Graph — toggle the panel, set f(x) and x-range, press Plot. Free variable must be x.
  • Theme — ◐ toggles light/dark chrome (saved locally).

How it’s implemented

This is a static web app: HTML, CSS, and JavaScript bundled with Vite. There is no backend API for calculations.

PieceRole
math.js Parses and evaluates expressions, units, and many numeric functions
Custom engine layer Normalizes friendly input (π, ×, √, implicit multiply), applies DEG/RAD to trig, factorial/nCr helpers, formatting, and plot sampling
KaTeX Optional pretty rendering of the last committed expression
Canvas plotter Samples y = f(x) and draws grid, axes, and the curve locally
localStorage Persists UI state and calculator memory on this origin only
GitHub Pages Hosts the built static files; the CDN only serves files, it does not compute your math

Source and issues: github.com/ryan-miles/open-source-math-calculator. Offline: run npm run build and open the single-file dist/index.html, or use the included .bat launcher on Windows.
